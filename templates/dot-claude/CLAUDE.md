# Project rules

Read this folder before the first action on a task: `memories/README.md`, any skill in `skills/` that matches the task, and the task's own `tasks/<slug>/README.md`.

- What a session learns that the next one needs goes into `memories/` (one fact per file, plus a line in its README) or a skill in `skills/<name>/SKILL.md`.
- Each task is a folder under `tasks/` holding one `README.md`, `evidence/` and `review/`; `tasks/INDEX.md` lists them.
- Nothing is committed, pushed, posted or published without the user's word.
